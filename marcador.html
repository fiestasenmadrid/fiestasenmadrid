Botón «Copiar fiestas»

Este botón lee las fiestas de tu página de Fourvenues y las copia listas para pegar en tu hoja de Google.

📋 Copiar fiestas

Instalarlo (una sola vez)

  1. Muestra la barra de marcadores de Chrome: Ctrl + Mayús + B.
  2. Arrastra el botón rosa de arriba hasta la barra de marcadores.

Usarlo cada día

  1. Abre tu página de Fourvenues y pulsa «Ver todos los eventos».
  2. Baja hasta el final de la lista para que carguen todas las fiestas.
  3. Pulsa el marcador 📋 Copiar fiestas. Te dirá cuántas ha copiado.
  4. En tu hoja de Google, haz clic en la celda A1 y pega con Ctrl + V.

La web se regenera sola cada mañana con lo que haya en la hoja. Si quieres que salga al momento, entra en GitHub › Actions › «Actualizar web de fiestas» › Run workflow.
